# Michael & Co. — Assets & Media Guide

This folder contains all visual placeholders for **Michael & Co.** (logo and high-resolution event imagery). All placeholders are currently vector SVGs that render crisp and luxury-styled across Retina and 4K displays.

---

### Tips:
- If you replace a file with a `.jpg` or `.png`, simply update the `src` attribute in `index.html` and `book.html` (e.g. `src="assets/images/gallery-1.jpg"`).
- We recommend compressing photographs using WebP or MozJPEG for optimal page speed.
